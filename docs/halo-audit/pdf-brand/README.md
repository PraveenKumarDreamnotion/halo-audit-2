## How to apply it

### 1. Fonts and engine set-up

In `Pdf::render()`, build mPDF from the brand config:

```php
$temp = trailingslashit(get_temp_dir()) . 'halo-audit-mpdf';
wp_mkdir_p($temp);
$mpdf = new \Mpdf\Mpdf(BrandPdf::config(SEO_ANALYZER_PLUGIN_DIR . 'assets', $temp));
$mpdf->SetTitle('Halo Audit');
$mpdf->SetAuthor('Thrivemattic');
$mpdf->WriteHTML(BrandPdf::css(), \Mpdf\HTMLParserMode::HEADER_CSS);
```

The config registers `lato`, `latoblack`, `oswald` (500, bold = 600) and `oswaldbold` (700),
makes `lato` the default, and turns on substitution with DejaVu Sans as the backup. That keeps
the status marks (✓ ✗ ○ ▲ ▼) and any non-Latin text from the audited page (for example a Hindi
title) printing correctly. `bin/build-zip.sh` already keeps the DejaVu fonts, so nothing changes there.

### 2. Two mPDF rules that cost time

Learned while making `reference.pdf`:

- **mPDF does not apply descendant selectors** such as `.cover h1` or `.cta .button`. The base
  rule `h1 { color: charcoal }` then wins, and a heading on the charcoal band is invisible.
  Inside dark blocks, set colour and font with inline `style=""`, as `render-reference.php` does.
- **Empty table cells collapse and `padding` on a `div` inside a cell is ignored.** Bars need a
  `&nbsp;` at `font-size:1pt` (see `BrandPdf::bar()`). For vertical space inside a cell, use a
  spacer `<div style="font-size:8pt;line-height:1">&nbsp;</div>`.

### 3. Layout, page by page

Follow `reference.pdf`:

- **Page 1:** charcoal cover band (white logo, olive-bright eyebrow, white Oswald title, page,
  competitor, keyword, date). Then the score row, the plain-language summary, four cream count
  tiles with an olive top rule, and the four area cards (olive bar for your page, grey for the
  competitor).
- **Running header from page 2:** dark logo, "Halo Audit · <report type>", host and date on the
  right. Footer: "Report generated by thrivemattic.com with Halo Audit" and "Page X of Y".
  `BrandPdf::headerFooter()` does both, and hides the header on page 1.
- **Findings:** a table per area: check name (charcoal bold) with the "why" line in grey, then a
  badge and the evidence for each page. "What to do" is a cream row with an olive left rule and a
  charcoal bold label.
- **Last block:** `BrandPdf::cta('thrivemattic.com/contact')`.

### 4. The download file name

The server already sends a name in `Content-Disposition`, but `public/js/halo-audit.js` overrides
it with `link.download = 'halo-audit.pdf'`. Read the server name instead:

```js
var disposition = response.headers.get('Content-Disposition') || '';
var match = /filename="([^"]+)"/.exec(disposition);
link.download = match ? match[1] : 'halo-audit.pdf';
```

(`response` is the fetch response; read the header before `response.blob()`.)

And make the server name specific, in `Pdf::filename()`:

- single page: `halo-audit-<host>-<YYYY-MM-DD>.pdf`
- comparison: `halo-audit-<host>-vs-<competitor-host>-<YYYY-MM-DD>.pdf`

### 5. Check it

The only checks that count are on the PDF itself:

```bash
pdffonts report.pdf      # must list Lato and Oswald. DejaVu may appear for symbols only. No Times.
pdftoppm -r 70 -png report.pdf page   # delete old PNGs first, then look at every page
pdftotext report.pdf - | grep -c "—"  # must print 0
```

To re-make the reference, from the repo root after `composer install` in `SEO-plugin/`:
`php docs/halo-audit/pdf-brand/render-reference.php SEO-plugin SEO-plugin/assets out.pdf`.
